# Uni Guide – Smart Campus App

Group project for **ITS 610204 / ITS 64604 Principles of Software Engineering**, Taylor's University, September 2026.

Uni Guide is a smart campus guide for students, lecturers and admins: campus map and routes, timetable, exam and deadline reminders, lecturer announcements and class cancellation alerts. The prototype is a high-fidelity clickable prototype built in Figma.

## How to add your work

1. Open the right folder on GitHub.
2. Click **Add file → Upload files** and drop in your file.
3. Write a short commit message that says what changed, e.g. `Add use case diagram v1` or `Update class diagram: add Notification class`.
4. Click **Commit changes**.

Rules:
- Upload diagrams twice: the **tool file** (.drawio, .vpp) and a **PNG export**.
- Name files `Section_Topic_vN`, e.g. `7_ClassDiagram_v2.png`.
- Upload a new version instead of deleting the old one when something changes. The commit history is our evidence for tool usage.
